#  Overview

HealthChain 360 is an AI-powered healthcare supply chain resilience platform designed to monitor, visualize, simulate, and respond to disruptions across critical healthcare supply networks.

The platform combines an interactive Digital Twin, real-time crisis simulation, healthcare supply-chain monitoring, AI-powered decision support, and AI-assisted emergency rerouting into one intelligent healthcare command center.

HealthChain 360 demonstrates how Artificial Intelligence and Digital Twin technology can work together to identify supply-chain risks, analyze disruptions, recommend operational actions, and improve healthcare supply-chain resilience.

The platform provides an interactive visualization of healthcare supply hubs, facilities, routes, network conditions, inventory risks, crisis progression, and AI-generated operational recommendations.

Google Gemini AI is integrated into the platform to provide contextual answers, crisis analysis, operational recommendations, and AI-assisted emergency rerouting decisions.

#  Installation

### Clone the repository

```bash
git clone https://github.com/chandrabignesh06/CrimeVision-AI.git
```

### Go to the project folder

```bash
cd CrimeVision-AI
```

### Install dependencies

```bash
npm install
```

### Create a `.env` file

```env
GEMINI_API_KEY=YOUR_GEMINI_API_KEY
```

### Start the server

```bash
npm start
```
